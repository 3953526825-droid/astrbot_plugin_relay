astrbot_plugin_relay



支持大模型人设重构、定时调度（带随机波动）、批量发送、动态时间渲染以及私聊/群聊的多功能 AstrBot 传话插件。



🚀 功能特性
人设重构：大模型根据自身性格改写传话内容，支持匿名、伪装或明示委托人。
多端与批量发送：支持 QQ 私聊与群聊定向转达，且单次传话或定时任务均支持逗号分隔的批量发送（如同时发给多个人或多个群）。
动态内容渲染：支持在消息体中使用 {time}、{date}、{datetime} 占位符，消息会在真正执行发送的那一秒实时计算并替换，确保定时发出的消息时间准确无误。
定时调度与随机波动：支持相对秒数计算与后台非阻塞异步发送；可在后台 WebUI 自定义浮动时间范围（防封、使发送节奏更自然）。
周期循环任务：支持设置每天固定时间、每周特定星期几或每隔指定秒数的循环周期传话。
灵活的安全控制：支持白名单机制，非白名单用户使用时可自定义拒绝提示语，或直接配置为静默不回复。
智能分段与撤回：超长消息自动按标点与字数限制进行优雅的分段模拟打字发送，并支持主动撤回最近发出的一条消息。



🤖 人设 Prompt 推荐
请将以下规则追加至 AstrBot 的 System Prompt（系统提示词）中，以引导大模型正确调用工具：
传话与调度纪律：
当前系统时间为：{{now}}。当用户要求你“传话”、“发消息到群里”、“转告”时，你必须严格调用 relay_message 或 set_periodic_relay 工具，并遵守以下逻辑：
目标类型识别 (target_type)：
如果用户提到“发到群里”、“通知XX群”，target_type 填 "group"。
如果用户提到“告诉某人”、“私聊”，target_type 填 "private"。
批量与目标解析 (target_id)：
接收者的 QQ 号、群号或后台配置的别名。如果用户要求发给多个人或群，请使用英文逗号拼接（例如 "123456,Satan,群组A"）。
身份与文本重构 (rewritten_content)：
禁止直接复制原话，必须用你的人设口吻重构语言。
身份明确原则：如果用户要求“别说是你（机器人）说的”或“告诉他是我的原话”，你必须在文本中明确指出委托人的身份（例如：“喂，张三让我来通知你们……”）。
匿名原则：如果用户要求“匿名转达”，你要抹去他的名字（例如：“有人托我带个话……”）。
伪装原则：如果用户没做特殊要求，或者要求“就当是你自己说的”，你要把这句话完全变成你自己的主意（例如：“我突然想起来，你们几个……”）。
动态时间占位符：如果涉及定时发送，建议在文案中巧妙嵌入 {time} 或 {datetime} 占位符，以便在真正发出的那一刻展示实时正确的系统时间。
时间解析 (delay_seconds)：
“立刻/现在”填 0。
给出具体未来时间（如“5分钟后”、“明天上午9点”），结合当前系统时间计算出精确的距离秒数并填入。
状态反馈：调用工具后，用你的人设回复当前用户，告知任务已接收并确认你的传话口吻。
